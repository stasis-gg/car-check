# 🚗 CarCheck Bot & Mini App

Комплексный Telegram-бот и Telegram Mini App для проверки автомобилей по 4 базам данных:
1. **Tolom.kg** (Кыргызстан): Проверка штрафов ГУОБДД («Безопасный город»), сведений о ТС, периодов владения, арестов и официального разрешения на тонировку.
2. **Customs.gov.kg** (Таможенная служба КР): Проверка таможенного оформления по VIN, решение таможни, дата и статус ДТ/ТПО.
3. **Korea-Cars.com** (Южная Корея): Проверка даты вывоза из Кореи, экспортного пробега, цвета, повреждений и заказ CarHistory.
4. **Cars.autopartner.by** (Аукционы Copart / IAAI): Поиск лотов с зарубежных аукционов США и Европы с фотографиями.

---

## 🚀 Запуск проекта

### 1. Активация виртуального окружения
```powershell
.\.venv\Scripts\Activate.ps1
```

### 2. Запуск приложения (Бот + Веб-сервер Mini App)
```powershell
python run.py
```

После запуска:
* **Telegram Бот:** автоматически начинает обрабатывать входящие сообщения в Telegram.
* **Mini App & API:** доступны локально по адресу `http://localhost:8000/`.

## 📱 Использование Telegram Mini App

Для того чтобы кнопка Mini App открывалась внутри Telegram клиента, веб-сервер должен быть доступен по HTTPS:
1. Запустите туннель (например, [ngrok](https://ngrok.com/) или [localtunnel](https://localtunnel.github.io/www/)):
   ```bash
   ngrok http 8000
   ```
2. Скопируйте полученный HTTPS адрес (например, `https://abc123.ngrok-free.app`) и укажите его в файле `.env`:
   ```env
   WEBAPP_URL=https://abc123.ngrok-free.app
   ```
3. Перезапустите `python run.py`.
4. В боте появится интерактивная кнопка **`📱 Открыть полный отчет`** прямо в Telegram!
